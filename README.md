## Pinned Projects

### Personal Knowledge Management (PKM) App

A personal knowledge management platform implementing PARA and GTD data organization methodologies.

- **Architecture:** Structured as a monorepo. The API backend is built using **Clean Architecture**, while the React client uses **Vertical Slice Architecture (VSA)**.
- **Database & Infrastructure:** Uses a PostgreSQL instance. Database mapping and migrations are handled through EF Core.
- **Logging:** Integrated Serilog for structured logging.
